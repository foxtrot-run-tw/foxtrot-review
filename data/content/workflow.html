怎麼做的

工作流程

這頁說明審查頁上的內容是怎麼做的、用了哪些工具、各輪大概花多少時間，以及圖片方向與 Instagram 輪播的改版紀錄。方便一起上來查看的人（包含協助審查的 Claude）不用再從對話裡拼湊脈絡。

一則內容怎麼走完

  1. 研究題目與來源。 依當日循環（A 傷害預防、B 台灣賽事、C 訓練知識）或當次實驗題目，找出需要打開的官方頁、衛教或研究文獻。
  2. 核對來源。 只採用真正打開過的網址。數字、日期、報名期限與結論分寸都依原頁；沒打開全文就註明；不確定的地方在文案裡明說。
  3. 依平台寫文案。 每日六平台會分別寫網頁、Threads、Instagram、Facebook、LinkedIn、X，不是同一篇剪短。輪播實驗則集中寫八張圖上短文與一則 caption。
  4. 產出照片候選。 用 AI 圖像生成寫實紀實風照片，一次準備多張候選。有 logo、可讀文字、怪手怪腳、可辨識的臉、結構畫錯或不對題的圖會直接捨棄，不修修補補再上稿。
  5. 用程式把字排上圖。 以 Python 與 Pillow 把標題、副標與頁腳排進新聞卡，字型用已安裝的 Noto Sans CJK TC Bold，重點字是橘色 #FF7A1A。
  6. 自我檢查。 對五項把關原則逐條看過，並在完整尺寸與約 360px 寬檢查文字是否仍清楚、圖片有沒有違規。
  7. 先給 Alfred 預覽。 還沒通過前，只放在工作目錄，不推上線。
  8. 依回饋修改。 改版型、換圖或改文案，直到明確通過。
  9. 才寫進這個審查站。 生成靜態頁、本地檢查，再推到 GitHub Pages。內容仍然不是社群發布。

使用的工具（白話）

  • AI 圖像生成： 用來產出紀實風照片候選，不負責圖上的中文標題。
  • Python 與 Pillow： 把選定的照片裁切、漸層、排字，組成 4:5、16:9 或 1:1 的新聞卡，以及 Instagram 輪播。
  • 靜態網站與 GitHub Pages： 審查站沒有建置伺服器端程式，頁面由腳本先生成 HTML，再放到這個 GitHub 倉的 Pages。倉是審查用帳號 foxtrot-run-tw 底下的 foxtrot-review，不是 Alfred 的個人社群帳號。

各輪大約花多久

第一天（2026 年 11 月 11 日）從研究、寫六個平台版本、建審查站，到多次改圖片方向與換成橘色，是分成好幾段完成的，不是單一輪的七分鐘就能做完。

之後較能對照的單輪時間大致如下（皆為台灣時間）：

  • Instagram 輪播各次改版，大約每次 4 到 7 分鐘。例如第三次改構圖與河堤約 4 分鐘，第四次讓每張圖對上文字約 7 分鐘。
  • 輪播通過後，把它加進審查站並加上版型篩選，大約 7 分鐘。

這些時間指的是「這一輪修改與產出」，不含稍早已經做完的研究與文案。

圖片方向怎麼演進

  1. 最早試過孔版／Risograph 風格的插畫風配圖。
  2. 改成寫實紀實照片，再由程式排成新聞卡（上方照片、下方深色面板與大標題）。
  3. 依回饋加入人物，並讓場景更接近台灣會出現的風景；同時放大副標與以下層級的字。
  4. 品牌強調色從紅色改成橘色 #FF7A1A，並更新已上線的審查頁。
  5. 輪播第一版曾把其中幾張改成文字為主、照片只留窄帶，被指出跑版（字跑到上方把圖遮了大半），之後全部改回「上圖下文」。
  6. 再來修掉畫錯的河堤、拿掉用來暗示「這是台灣」的破舊房子，並讓構圖有半身、特寫與無人場景的變化，不再連張都是全身背影。
  7. 風格通過後，再要求每一張輪播的照片必須清楚對應那張的文字，不能只是氣氛圖。

Instagram 輪播的四次改版

題目是「新手跑者常見的 5 個傷害警訊」，共八張、4:5、1080×1350，只做 Instagram，沒有發布。

  1. 第一版： 建立八張輪播與文案。其中第 3、7、8 張用了偏文字的版型；有些照片重複使用。
  2. 第二版： 回饋指出第 3、7、8 張跑版，且除封面外每張圖應該不同。於是全部改回上圖下文，並讓各張使用獨立照片。當時構圖偏重複，場景也還有不少房子。
  3. 第三版： 回饋指出第四張的河堤幾何完全畫錯，而且前面幾張不需要靠破舊房子來代表台灣，人物也不必都是全身背影。這輪改掉河堤、拿掉無關的舊公寓，並變化構圖。圖片風格在這版獲得通過。
  4. 第四版： 回饋是「圖片沒問題了，但是多數圖的內容跟文字完全沒關聯」。這輪讓封面、五個警訊、清單與行動呼籲的照片都對上各自的文字（停跑按膝、步伐走樣、按脛骨、愈跑愈痛而減速、夜間冰敷、下樓按膝前側、坐下檢查、收操慢走）。此版通過後，才放上審查頁。

第四版仍有一個已知限制，寫在該則的自我檢查裡：第 2 張（步伐走樣了）看得出人在跑道上移動，但跛行幅度比較含蓄，不是非常明顯的一腳代償。

以後要新增一則時

在 data/days.js 追加一筆資料，必要時把新圖放到 images/，然後執行：

python3 scripts/build_review_site.py

腳本會重寫首頁目錄與各則靜態頁。先本機打開檢查（即使關掉 JavaScript 也應能讀到正文、來源與圖片），通過後再提交。完整欄位與規則見 首頁與倉裡的 README。
